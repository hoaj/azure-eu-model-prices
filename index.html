Prices are zone-wide

Data Zone Standard token prices are billed at the EU-zone level — identical for Sweden Central and West Europe. The region toggle changes availability, not price.

Context tiers

gpt-5.4 / gpt-5.5 / gpt-5.6 show the short-context rate. Long-context and pro tiers are billed higher — see the pricing page.

What's excluded

Cached-input, Batch and Provisioned rates are not shown. ada-002 has no Data Zone meter (price n/a). Audio / realtime / image / router models are out of scope.

Reasoning effort

A model's default reasoning_effort is an OpenAI API default; Azure and Cognigy inherit it (Cognigy's node has no reasoning control). Most reasoning models default to medium — gpt-5.1 is none; gpt-5.4 and gpt-5.6 undocumented; gpt-4.x / gpt-4o & embeddings have none. gpt-5.6 adds a max level (Responses API only). Supported levels per Azure. Click the ▸ on a row to see them (default highlighted), each carrying its τ³ score where Artificial Analysis measured one — a faded pill means Azure supports that tier but AA never scored it.

Agentic τ³ benchmark

Agentic τ³-Banking score (% of tasks solved) from Artificial Analysis — higher is better. 97 support tasks where the agent must find the right policy among ~700 documents and run the correct multi-step tool sequence, graded on backend state rather than chat quality. Uses AA's highest-effort variant, so the reasoning tier varies (gpt-5.6 at max, gpt-5.4/5.5 at xhigh, gpt-5/5.1 at high); hover a score for the exact variant. It is a hard benchmark — the leaderboard tops out near 33%. — = not on the leaderboard (embeddings, gpt-4.1, gpt-4o, gpt-5-nano, the o-series).

Comparing at equal effort

In Best mode each model shows the highest effort AA ran it at, so the column mixes tiers — gpt-5.6 at max against gpt-5 at high. Pick a tier in τ³ at effort to re-key the column and rank every model on the same amount of thinking; sorting follows what's displayed. — then means AA didn't run that model at that tier (hover to tell the two kinds of — apart). Only gpt-5.5 and the three gpt-5.6 models have a full ladder; the rest were run at a single tier. Expand a row (▸) to see a model's whole curve — that's where diminishing returns show up, e.g. gpt-5.6-sol gains just 0.4 points going from xhigh to max, while gpt-5.6-terra gains 7.5.
